01 / Spreadsheet automationv0.1.1 · Windows

SheetForge

From inconsistent exports to useful data.

Combine supplier, customer or operations exports into a consistent dataset. Replace repeated spreadsheet cleanup with saved, reviewable processing rules.

  • Merge CSV/XLSX files and map different column names.
  • Normalize blanks, whitespace and common dates; deduplicate by combined keys.
  • Filter and split records, export CSV/XLSX, and keep anomaly audits and HTML summaries.

Python 3.12 · tkinter/ttk · openpyxl · csv · SQLite

Repository ↗Download Windows ZIP ↗

Public v0.1.1 · portable Windows x64 · unsigned. SHA-256 checksums. Extract the complete folder before running.

How to try SheetForge
  1. Extract the entire Windows portable ZIP; keep the application folder together.
  2. Run SheetForge.exe and load the included synthetic customer files.
  3. Map Customer to Name, deduplicate on Email, then review the exported data and report.
Full quick start · Review sample input and expected output

Portable binaries are unsigned. Use only approved data; all processing stays local.

Known limits & validation

First worksheet only. XLSX exports use text cells; workbook styling, macros and formula calculation are not preserved.

02 / Windows file workflowsv0.1.1 · Windows

FolderPilot

Review the plan. Then change the files.

Bring order to a selected working folder: standardize filenames, organize deliveries, find duplicates and create verified backups with a preview-first workflow.

  • Batch replacements, regex rules and numbering; organize by type, modification date or size.
  • Read-only SHA-256 duplicate detection, verified backups and version-preserving incremental sync.
  • Dry Run, explicit confirmation, conflict protection, recovery journals and notify-only folder monitoring.

Python 3.12 · tkinter/ttk · pathlib · hashlib · JSON

Repository ↗Download Windows ZIP ↗

Public v0.1.1 · portable Windows x64 · unsigned. SHA-256 checksums. Extract the complete folder before running.

How to try FolderPilot
  1. Extract the Windows portable ZIP and run FolderPilot.exe.
  2. Select an approved sample folder and choose rules; click Preview (Dry Run).
  3. Review destinations before executing. Keep the operation journal for eligible recovery.
Full quick start · Review sample files and saved rules

Portable binaries are unsigned. Use only approved data; all processing stays local.

Known limits & validation

Content backup does not preserve ACLs or alternate streams. Sync is one-way and keeps earlier versions; it does not mirror deletions. Use quiet local folders.

45 local tests passed; one privilege-dependent symlink test skipped. Windows/Linux CI, real Tk execution/recovery and packaged core checks passed for the public snapshot.

03 / Security log analysisv0.1.0 · Windows

LogSentry

Understand the event. Keep the evidence.

Turn exported SSH, Windows Security XML and web access logs into searchable events, explainable findings and an English report for system owners.

  • Batch log parsing, explicit UTC normalization, raw evidence snapshots and indexed event queries.
  • Configurable login and web rules, IP/account summaries and hourly event trends.
  • Evidence-linked findings and escaped HTML/JSON reports that separate facts, rule inferences and recommendations.

Python 3.12 · tkinter/ttk · SQLite · defusedxml

Repository ↗Download Windows ZIP ↗

Public v0.1.0 · portable Windows x64 · unsigned. SHA-256 checksums. Extract the complete folder before running.

How to try LogSentry
  1. Extract the Windows portable ZIP; run LogSentry.exe --demo for synthetic data.
  2. Open Findings and select Analyze current scope; inspect the linked evidence.
  3. Generate the HTML and JSON summary from Reports and review the stated limitations.
Full quick start · Review synthetic logs and expected findings

Portable binaries are unsigned. Use only approved data; all processing stays local.

Known limits & validation

Windows input is exported XML (4624/4625), not native EVTX. Legacy syslog needs a confirmed year and offset. Rule matches do not prove an intrusion.
